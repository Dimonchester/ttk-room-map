# ttk-room-map

```git clone git@github.com:Dimonchester/ttk-room-map.git``` - скачать себе проект

```node scripts/init-env.js```                  # backend/.env из backend/.env.example

```go run ./cmd/api/main.go```                  запуск бэка (из ~/backend)

```npm run dev```                               запуск фронта (из ~/frontend)
